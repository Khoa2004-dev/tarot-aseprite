MAJOR ARCANA — COMPLETE PIXEL ART SET

22 individual .aseprite files, numbered 00–21.
Canvas: 97 x 181 pixels, matching the supplied deck.
Each file contains three editable raster layers: Frame, Artwork, Number.
Artwork is flattened within its layer; individual objects are not separated.
The previews folder contains native-size PNG exports.
Major_Arcana_Overview.png shows the complete collection at 2x nearest-neighbor scale.

Style: gold frames, limited palettes, crisp pixel shapes and featureless human faces.
Compositions are inspired by the 1909 Rider–Waite–Smith Major Arcana,
with classical drapery added to several figures. The approved corrected Fool is included.

AI-assisted artwork generated with the built-in image generation tool,
then converted to the deck canvas and encoded as layered Aseprite files.
